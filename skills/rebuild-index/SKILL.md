# /rebuild-index

Walk `records/**/*.md` and `topics/*.md`, read each frontmatter, regenerate `index.md` at the workspace root.

## Procedure

1. **Walk Records.** For each `records/{class}/*.md`:
   - Read frontmatter `type`, `id`, `title`, `status`, `date`, `party` (where present).
   - Group by `type` (and within Amendments, by `party`: GC vs architect).

2. **Walk Topics.** For each `topics/*.md` that isn't `README.md`:
   - Read frontmatter `slug`, `title`, `status`, `last_synthesized`.

3. **Write `index.md`** following this structure:

```markdown
# Index

Unified entity catalog for the wiki. **Agents read this first** to find the relevant entity class or topic page, then drill into Records.

> Regenerated by `/rebuild-index`. Do not hand-edit. New entities appear automatically when `/ingest` runs.

## How to use this index

[ … preserve the boilerplate from the previous index.md … ]

---

## Topics

- [{title}](topics/{slug}.md): _{status}; last synthesized {date}_

## Contracts

### Base Contracts
- [{ID}](records/contracts/{ID}.md): {title}

### GC Amendments
- [{ID}](records/contracts/{ID}.md): {title}

### Architect Amendments
- [{ID}](records/contracts/{ID}.md): {title}

## OAC Meetings
- [{ID}](records/oac/{ID}.md): {title}

[ … and so on for ASIs, Changes, RFIs, Pay Apps … ]

---

## Out-of-scope (Originals only, no Records)
[ … preserve from previous … ]
```

4. **Sort each section** by `id` (naturally: `Amendment-GC-01`, `-02`, …, `-07`; `OAC-001` through `OAC-NNN`).

5. **Don't include any numerical content** in the index: no counts, no totals, no dollar figures. The lint will fail you.

6. **Don't include `topics/README.md`** as a topic.

7. **If a Record's frontmatter is missing `title`**, use the `id` as the link text and append `: title pending` in italics.

8. **Append to `log.md`** only if the regenerated index differs from the previous version: `## [YYYY-MM-DD] system | rebuild-index | {N records, M topics}`. (Counts in the log are fine; counts in `index.md` are not.)

## Edge cases

- A Record under `records/{class}/` with `type` not matching the folder is a violation. Flag it via lint, but include it under its declared `type` in the index.
- If `records/` is empty, write the skeleton with "(none ingested yet)" under each section. This is the bootstrap state.
